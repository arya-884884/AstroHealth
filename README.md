# AstroHealth

**Astronaut Health Monitoring Software**\
NASA Space Apps Challenge 2026

## About the Project

AstroHealth is a health monitoring application developed as part of the
NASA Space Apps Challenge 2026. It is designed to help astronauts
monitor their health during long-duration space missions.

Space missions expose astronauts to health risks such as radiation,
isolation, altered gravity, bone loss, cardiovascular changes and sleep
disturbances. AstroHealth aims to help astronauts keep track of
important health indicators and recognise possible health concerns.

## Features

-   Monitors vital signs such as heart rate, SpO₂ and body temperature.
-   Tracks sleep and exercise.
-   Displays health status indicators.
-   Provides alerts for unusual health readings.
-   Presents health information through a monitoring dashboard.
-   Tracks mission duration.
